# Phase 8H — Mobile Commerce Experience

This update changes only the public mobile storefront presentation.

## Included
- Full-width mobile search field directly below the header.
- More compact 64px mobile header and better logo proportions.
- Shorter 410px hero so customers reach shopping content sooner.
- 31px mobile hero heading with natural wrapping.
- Compact two-button hero actions.
- Four departments visible at once in a 4-column quick-shop grid.
- Short mobile-only department labels.
- Denser Best Sellers / New Arrivals horizontal product rails showing roughly two cards at once.
- Smaller promo tiles and tighter mobile section spacing.
- Desktop and tablet storefront behavior is preserved.

## No database changes
No Supabase migration is required.
