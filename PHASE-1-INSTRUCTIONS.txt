WOW & AMAZING — PHASE 1 FOUNDATION

This package contains the completed Phase 1 foundation only:
- Tailwind CSS v4 design tokens from Section 2
- Inter + Playfair Display font setup with the locked fallbacks
- Utility Bar skeleton
- Main Header skeleton and mobile navigation drawer
- Footer skeleton
- Exact logo variants in public/brand
- Supabase schema, indexes, search preparation, helper functions, and RLS policies
- Port 3004 remains configured in package.json

HOW TO INSTALL WITH WINDOWS CMD

1. Stop the development server with Ctrl + C.

2. Make a backup:
   cd /d "%USERPROFILE%\Desktop"
   ren wow-and-amazing wow-and-amazing-backup

3. Extract this ZIP on the Desktop, then rename the extracted folder to:
   wow-and-amazing

4. Enter the project:
   cd /d "%USERPROFILE%\Desktop\wow-and-amazing"

5. Install/repair dependencies:
   npm install

6. Verify:
   npm run lint
   npx tsc --noEmit
   npm run build

7. Run:
   npm run dev

8. Open:
   http://localhost:3004

SUPABASE

Open Supabase Dashboard > SQL Editor > New query.
Paste and run:
   supabase\migrations\202607120001_foundation_schema.sql

Do this once on a new Supabase project/database.
Do not expose SUPABASE_SERVICE_ROLE_KEY in browser code.
